# Session 66: Polish groundwork

Nothing looks or plays different yet. This session only adds the shared pieces that Sessions 67
to 71 need, so those five can be built at the same time by different agents without editing the
same files. Built exactly as docs/polish_plan.md Appendix C, plus the small fixes listed below.

## What works

- **`PolishHooks` autoload** (`scripts/polish_hooks.gd`). When the game world
  (`res://scenes/wahat_al_shams.tscn`) is added to the tree, it waits until the end of that
  frame (so every builder's `_ready` has run), then for each of the 5 reserved files in `PARTS`
  that exists it loads it and calls its `static func attach(world: Node)`. Missing files are
  skipped. Runs once per world. Switch: `GameConfig.POLISH_HOOKS_ON`.
  - `attached` (which parts ran) and `last_world` are there for tests.
  - `attach_parts(world, paths)` runs a list by hand (for tests on the flat test area or bare
    nodes); `parts` is the list used when the world opens (a test may swap it, then put
    `PARTS` back).
- **`scripts/polish/`** folder with a README. Empty until Sessions 67 to 71.
- **`UiPalette`** (`ui/palette.gd`): PRD colours, meter band colours (normal and colour help),
  font sizes, motion times, `band_colour(band)`.
- **`UiJuice`** (`scripts/ui_juice.gd`): `pop_in`, `press`, `count_up`, `shake`, `slide_in`. All
  tweens keep running while paused; Less motion turns shake off and halves pop_in.
- **`UiSounds` autoload** (`scripts/ui_sounds.gd`): `UiSounds.play("ui_click")`. Loads
  `res://assets/audio/<key>.wav` for the 9 keys if the file exists (none do yet; Session 71
  makes them). Missing = silent. Counts every play in `play_counts` (tests read it). Effects bus,
  works while paused, silent in headless runs.
- **Saved settings** (`scripts/settings.gd`, section `"access"` of user://settings.cfg):
  `text_size` (0/1/2 = 100/115/130%), `colour_assist`, `reduce_motion`, `minimap_north_up`,
  `outlines`. Clamped on load; old settings files without the section keep the defaults.
  Text size is applied as the window's `content_scale_factor` in `Settings.apply()` (not in
  headless runs). Helpers: `Settings.text_scale()`, `Settings.apply_text_size(window)`.
  Nothing shows them in the Settings screen yet (Session 71 does, in settings_panel.gd).
- **GameConfig** section `# --- Session 66: polish groundwork ---` at the end, with every polish
  flag from the plan.
- **Tests**: new `tests/polish_groundwork_test.gd` (+ helper `tests/polish_test_part.gd`), 30
  checks, about 5 s. Added to tools/build-web.sh. Smoke has one new check at the end
  (`_check_polish_hooks`: the hooks ran for the world, and listed exactly the parts that exist).

## What I changed from Appendix C, and why

1. **The hooks also look for a world that's already there when they start.** Test scripts
   (the smoke test) add the world in `_initialize()`, before autoloads are ready, so the
   `node_added` signal missed it. `_ready()` now also checks the root's children. In the game
   the world opens later, so this changes nothing there.
2. **Once per world**: a `polish_hooks_done` meta on the world stops a second attach if the
   world is removed and added again.
3. **`parts` variable and `attach_parts()`**: so the test can use a stand-in part without
   writing files into scripts/polish/ (which the parallel sessions own).
4. **`UiJuice.shake` with Less motion** returned a tween with nothing in it, which Godot reports
   as an error ("started with no Tweeners"). It now has a zero-length step, so it finishes at
   once and `await t.finished` still works.

## Does `ResourceLoader.exists()` work for .gd files in an exported game? Yes.

Checked for real: a tiny project with `scripts/polish/look_extras.gd`, exported with
`--export-pack Web` and the same `script_export_mode=2` (compressed binary tokens) as our
presets, then run with `--main-pack`. Inside the pack the file is stored as `look_extras.gdc`
plus `look_extras.gd.remap`; there's no `.gd`. Results:
`ResourceLoader.exists("…/look_extras.gd")` = true, a missing part = false,
`FileAccess.file_exists("…/look_extras.gd")` = **false** (so never use FileAccess for this),
and `load()` + `call("attach", world)` ran. The release run will prove it again in the browser
once a part exists.

## The contract for Sessions 67 to 71 (parallel agents)

1. **World extras file**: put ONE file at your reserved path and nowhere else:
   67 `scripts/polish/look_extras.gd`, 68 `world_extras.gd`, 69 `hud_extras.gd`,
   70 `phone_extras.gd`, 71 `screen_extras.gd`. Don't edit `polish_hooks.gd` or its list.
2. It must have `static func attach(world: Node) -> void` (`extends RefCounted` or Node; no
   class_name needed). It runs once, at the end of the frame the world opens (all builders'
   `_ready` done). Add your nodes as children of `world`. If you need something built later,
   add a Node of your own and wait in it. Don't assume the bike, HUD etc. exist without
   `get_node_or_null`.
3. Check your own GameConfig flag inside attach (e.g. `if not GameConfig.WATER_V2: return`).
   The flags are in the Session 66 section; put new numbers in your own `# --- Session NN ---`
   section at the end of game_config.gd.
4. Settings: read `Settings.text_size` / `Settings.text_scale()`, `Settings.colour_assist`,
   `Settings.reduce_motion`, `Settings.minimap_north_up`, `Settings.outlines`. Only Session 71
   edits `settings_panel.gd`; nobody else edits `settings.gd`. After changing one, call
   `Settings.save()` (it saves and applies, including the text size).
5. Colours and sizes: `UiPalette.TEAL`, `.ORANGE`, `.SUN`, `.SAND`, `.INK`, `.PANEL`,
   `.SOFT_TEXT`, `.CYAN`, `UiPalette.band_colour(0|1|2)`, `FONT_SMALL/BODY/LABEL/TITLE/BIG`,
   `FAST/PANEL_TIME/REVEAL`. Don't copy colour constants into new files.
6. Animation: `UiJuice.pop_in(c)`, `press(c)`, `count_up(label, from, to, time, "%d Dh")`,
   `shake(c)`, `slide_in(c, Vector2(320, 0))`. All return a Tween; they run while paused and
   follow Less motion.
7. Sound: `UiSounds.play("ui_click", pitch)`. Keys: ui_hover, ui_click, ui_open, ui_close, tick,
   meter_warn, level_up, stamp, whoosh. Files are `assets/audio/<key>.wav` (Session 71 makes
   them); missing = silent. Tests can read `UiSounds.play_counts`.
8. Tests on a bare scene or the test area: call
   `root.get_node("PolishHooks").attach_parts(world, ["res://scripts/polish/your_extras.gd"])`.
   In the smoke test, `PolishHooks.attached` lists the parts that ran.
9. Shared files: game_config.gd (own section at the end), tools/build-web.sh (one suite name),
   tests/smoke_test.gd (one check function at the end plus one call in `_finish()`, after
   `_check_polish_hooks()`).
